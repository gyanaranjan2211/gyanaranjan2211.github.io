GYANARANJAN SAHOO — PERSONAL WEBSITE
=====================================

Files:
- index.html: website page
- images/: the five photos used in the gallery

PREVIEW:
Open index.html in a browser.

FREE PUBLISHING WITH GITHUB PAGES:
1. Sign in to GitHub.
2. Create a PUBLIC repository named exactly: your-github-username.github.io
   (replace your-github-username with your actual GitHub username).
3. Upload index.html and the entire images folder to the repository root.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for GitHub Pages to publish. Your site address will be:
   https://your-github-username.github.io/

GOOGLE SEARCH:
After publishing, add the website to Google Search Console and request indexing.
Google decides whether and when to show pages/images in results; indexing is not guaranteed.
Use a public-facing email or social link only if you want it shown. Avoid posting private contact details.
